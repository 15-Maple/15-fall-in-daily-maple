## 기능 명세
 
| 기능명 | 분류 | 기능 상세 설명 (어떤 동작을 하는지) |
| --- | --- | --- |
| 로그 목록 조회 | 로그 | 페이지네이션, 검색 기능, 포인트 순 정렬(오름차순/내림차순), 최신 순 정렬, 오래된 순 정렬을 제공 |
| 최근 조회한 로그 | 로그 | LocalStorage를 활용하여 최근에 조회한 로그를 표시 |
| 로그 생성 | 로그 | 닉네임, 로그 이름, 소개, 배경, 비밀번호 및 비밀번호 확인을 입력하여 로그를 생성 |
| 로그 상세 조회 | 로그 | 로그 이름, 생성자 닉네임, 소개글, 배경, 포인트 등 기본 정보를 조회 (비밀번호 불필요, 공개) |
| 로그 수정 | 로그 | 비밀번호 확인 후 로그 정보(이름/소개/배경) 수정 |
| 로그 삭제 | 로그 | 비밀번호 확인 후 로그 삭제 |
| 응원 이모지 조회 | 로그 | 로그에 달린 응원 이모지를 종류별 개수로 상위 N개 조회 |
| 응원 이모지 추가 | 로그 | 로그 상세 페이지에서 응원 이모지 반응 추가 (비밀번호 불필요, 익명) |
| 습관 기록표(주간뷰) 조회 | 로그 | 로그 상세 페이지에 표시되는 요일별 습관 체크 매트릭스를 주 단위로 조회 |
| 오늘의 습관 조회 | 습관 | 비밀번호 확인 후 접근 가능. 현재 시간과 오늘의 습관 목록(체크 여부 포함)을 조회 |
| 오늘의 습관 생성 | 습관 | 매일 반복될 습관을 이름만 입력해 설정, 등록한 날부터 목록에 추가됨 |
| 오늘의 습관 수정 | 습관 | 습관 이름 수정 시 이전에 연관된 모든 기록의 습관명도 함께 변경 |
| 오늘의 습관 삭제 | 습관 | 습관을 비활성화(soft delete) 처리, 오늘 이후 목록에서는 빠지지만 이전 기록은 그대로 보존 |
| 오늘의 습관 체크 | 습관 | 습관을 체크/체크 해제, 체크 여부는 매일 초기화되며 로그 상세의 습관 기록표에 반영 |
| 오늘의 집중 조회 | 집중 | 비밀번호 확인 후 접근 가능. 현재 포인트와 진행 중인 집중 세션을 조회 |
| 오늘의 집중 시작 | 집중 | 타이머로 목표 공부 시간을 설정하고 시작 버튼을 눌러 집중 세션 시작 |
| 오늘의 집중 완료 | 집중 | 목표 시간이 종료되면 집중 완료 처리, 기본 3P + 10분당 1P 포인트 획득 |
