## ✨ 주요 기능

### 📓 로그
- 닉네임, 이름, 소개, 배경 테마, 비밀번호를 입력해 나만의 로그를 만들 수 있어요
- 로그 목록을 검색하고 최신순 · 오래된순 · 포인트순(오름/내림차순)으로 정렬해서 둘러볼 수 있어요
- 최근에 들어갔던 로그는 자동으로 다시 보여줘요
- 로그 상세 페이지에서 소개, 포인트, 응원 이모지, 한 주간의 습관 기록표를 한눈에 볼 수 있어요
- 응원 이모지로 다른 사람의 로그를 응원할 수 있어요
- 비밀번호로 본인 확인 후 로그 정보를 수정하거나 삭제할 수 있어요

### ✅ 오늘의 습관
- 매일 반복할 습관을 등록하고, 오늘 지켰는지 체크할 수 있어요
- 체크 여부는 매일 초기화되고, 지난 기록은 로그 상세의 습관 기록표에 그대로 남아요
- 습관 이름을 바꾸면 과거 기록에도 함께 반영돼요
- 더 이상 하지 않는 습관은 삭제할 수 있고, 이전 기록은 지워지지 않아요

### ⏱️ 오늘의 집중
- 원하는 공부 시간만큼 타이머를 맞추고 집중을 시작할 수 있어요
- 집중을 끝까지 마치면 기본 3포인트 + 10분마다 1포인트씩 획득해요
- 모은 포인트는 로그 상세 페이지에서 확인할 수 있어요

## 🌿 브랜치 전략

```
main        # 배포 가능한 안정 버전
 └─ develop # 기능 통합 브랜치
     └─ feature/이슈번호-기능이름   # 개별 기능 개발
     └─ fix/이슈번호-버그내용       # 버그 수정
```


- 모든 작업은 `develop`에서 브랜치를 분기하여 진행합니다.
- 작업 완료 후 `develop`으로 Pull Request를 생성합니다.
- 최소 1명 이상의 리뷰 승인 후 병합합니다.
- 일정 주기로 `develop` → `main` 병합 및 릴리즈를 진행합니다.

## 📂 폴더 구조

### Frontend
```
📦src
 ┣ 📂api
 ┣ 📂assets
 ┣ 📂components
 ┃ ┣ 📂common
 ┃ ┗ 📂layout
 ┣ 📂constants
 ┣ 📂hooks
 ┣ 📂pages
 ┣ 📂utils
 ┣ 📜App.jsx
 ┣ 📜index.css
 ┗ 📜main.jsx
```

- `api/` : 백엔드 API 통신 관련 코드 (axios or fetch)
- `assets/` : 이미지, 아이콘 등 정적 파일
- `components/` : 화면을 구성하는 UI 조각들 (도메인별로 폴더를 나누어 작업합니다: habit, log 등)
- `constants/` : 프로젝트 공통 상수 (에러 메시지 등)
- `hooks/` : 커스텀 훅 모음
- `pages/` : 브라우저 URL과 1:1로 매칭되는 전체 화면 도화지
- `utils/` : 날짜 변환 등 공통 도우미 함수

## 🤝 Git 협업 규칙 및 자동화 도구

협업 자동화 도구가 프로젝트에 적용되어 있습니다. `npm install`을 하면 자동으로 세팅이 완료됩니다.

### 3가지 자동화 도구의 역할

- **🐶 Husky (허스키):** 여러분이 커밋을 시도할 때, 코드가 잘 짜였는지 규칙을 검사하도록 명령을 내리는 깃(Git) 훅 관리자입니다.
- **📦 lint-staged:** 전체 파일이 아닌, **여러분이 이번에 수정한 파일만** 골라서 문법 검사(ESLint)와 자동 정렬(Prettier)을 실행해 줍니다.
- **📝 Commitlint:** 커밋 메시지가 우리 팀 규칙에 맞는지 검사하고, 틀리면 커밋을 막아줍니다.

## 💻 사용 가능한 스크립트 명령어

- `npm run dev` : 개발용 서버를 켭니다.
- `npm run lint:fix` : 자바스크립트 문법 에러를 검사하고, 고칠 수 있는 건 자동으로 고칩니다.
- `npm run format` : 프로젝트 전체 파일의 띄어쓰기/줄바꿈을 일괄 정렬합니다.

## 🤝 기여 방법
