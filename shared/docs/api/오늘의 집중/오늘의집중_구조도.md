# 오늘의 집중 API 구조도 (3개)

프론트 → 백엔드 → DB 관계를 API 1개당 다이어그램 1개로 정리했습니다.

---

## 1. 오늘의 집중 조회

`GET /api/logs/{logId}/focus`

```mermaid
flowchart LR
  FE["프론트\n오늘의 집중 화면"] -->|"GET /api/logs/{logId}/focus"| BE["백엔드\n집중 조회"]
  BE -->|"SELECT points"| DB1[("logs")]
  BE -->|"SELECT WHERE status=진행중"| DB2[("focus_records")]
```

---

## 2. 오늘의 집중 시작

`POST /api/logs/{logId}/focus`

```mermaid
flowchart LR
  FE["프론트\n오늘의 집중 화면\n(Start!)"] -->|"POST /api/logs/{logId}/focus\n{targetSeconds}"| BE["백엔드\n집중 시작"]
  BE -->|"INSERT (status=진행중,\ncreated_at=now)"| DB1[("focus_records")]
```

---

## 3. 오늘의 집중 완료

`PATCH /api/focus-records/{focusId}/complete`

```mermaid
flowchart LR
  FE["프론트\n오늘의 집중 화면\n(타이머 종료)"] -->|"PATCH /api/focus-records/{focusId}/complete"| BE["백엔드\n집중 완료"]
  BE -->|"① UPDATE status=완료, ended_at=now"| DB1[("focus_records")]
  BE -->|"② UPDATE points += pointsEarned"| DB2[("logs")]
  BE -->|"③ INSERT 적립 내역"| DB3[("point_histories")]
```
