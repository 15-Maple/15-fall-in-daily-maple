# 로그 API 요청 흐름도 (8개)

API 1개당 요청/응답 시퀀스를 1개 다이어그램으로 정리했습니다.

---

## 1. 로그 목록 조회

`GET /api/logs`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(메인화면)
    participant BE as 백엔드
    participant DB as DB(logs, reactions)

    U->>FE: 검색어 입력 / 정렬 선택
    FE->>BE: GET /api/logs?keyword&sort&cursor&size
    BE->>DB: SELECT logs (조건/정렬/커서 적용)
    BE->>DB: SELECT reactions 상위 3개 (로그별)
    DB-->>BE: 로그 목록 + topReactions
    BE-->>FE: 200 OK {content, nextCursor, hasNext}
    FE-->>U: 로그 카드 목록 렌더링
```

## 2. 로그 생성

`POST /api/logs`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(로그 생성)
    participant BE as 백엔드
    participant DB as DB(logs)

    U->>FE: nickname/name/description/background/password 입력
    FE->>BE: POST /api/logs
    BE->>BE: password == passwordConfirm 검증
    alt 검증 실패
        BE-->>FE: 400 Bad Request
    else 검증 성공
        BE->>DB: INSERT INTO logs
        DB-->>BE: logId 반환
        BE-->>FE: 201 Created {logId, ...}
        FE-->>U: 로그 상세 화면 이동
    end
```

## 3. 로그 상세 조회

`GET /api/logs/{logId}`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(로그 상세)
    participant BE as 백엔드
    participant DB as DB(logs)

    U->>FE: 로그 카드 클릭
    FE->>BE: GET /api/logs/{logId}
    BE->>DB: SELECT * FROM logs WHERE id=logId
    alt 존재하지 않음
        DB-->>BE: 결과 없음
        BE-->>FE: 404 Not Found
    else 존재함
        DB-->>BE: 로그 정보
        BE-->>FE: 200 OK
        FE-->>U: 로그 상세 화면 렌더링
    end
```

## 4. 로그 수정

`PATCH /api/logs/{logId}`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(로그 상세 - 수정하기)
    participant BE as 백엔드
    participant DB as DB(logs)

    U->>FE: password + 수정할 name/description/background 입력
    FE->>BE: PATCH /api/logs/{logId}
    BE->>DB: SELECT password WHERE id=logId
    alt 비밀번호 불일치
        BE-->>FE: 403 Forbidden
    else 비밀번호 일치
        BE->>DB: UPDATE logs SET name/description/background
        DB-->>BE: 갱신 완료
        BE-->>FE: 200 OK {updatedAt, ...}
        FE-->>U: 수정된 정보로 화면 갱신
    end
```

## 5. 로그 삭제

`DELETE /api/logs/{logId}`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(로그 상세 - 삭제하기)
    participant BE as 백엔드
    participant DB as DB(logs 외 5개 테이블)

    U->>FE: password 입력 후 삭제 확인
    FE->>BE: DELETE /api/logs/{logId} {password}
    BE->>DB: SELECT password WHERE id=logId
    alt 비밀번호 불일치
        BE-->>FE: 403 Forbidden
    else 비밀번호 일치
        BE->>DB: DELETE FROM logs (habits/habit_histories/focus_records/point_histories/reactions CASCADE)
        DB-->>BE: 삭제 완료
        BE-->>FE: 204 No Content
        FE-->>U: 메인화면으로 이동
    end
```

## 6. 응원 이모지 조회

`GET /api/logs/{logId}/reactions`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(로그 상세)
    participant BE as 백엔드
    participant DB as DB(reactions)

    U->>FE: 로그 상세 화면 진입
    FE->>BE: GET /api/logs/{logId}/reactions?limit=3
    BE->>DB: SELECT reactionType, COUNT(*) GROUP BY reactionType ORDER BY COUNT DESC LIMIT 3
    DB-->>BE: 이모지별 집계
    BE-->>FE: 200 OK {reactions:[...]}
    FE-->>U: 상위 3개 이모지 + 개수 표시
```

## 7. 응원 이모지 추가

`POST /api/logs/{logId}/reactions`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(로그 상세)
    participant BE as 백엔드
    participant DB as DB(reactions)

    U->>FE: 이모지 선택
    FE->>BE: POST /api/logs/{logId}/reactions {reactionType}

        BE-->>FE: 400 Bad Request

        BE->>DB: INSERT INTO reactions
        DB-->>BE: 누적 개수
        BE-->>FE: 201 Created {reactionType, count}
        FE-->>U: 이모지 개수 즉시 반영
    end
```

## 8. 습관 기록표(주간뷰) 조회

`GET /api/logs/{logId}/habit-records`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(로그 상세 - 습관 기록표)
    participant BE as 백엔드
    participant DB as DB(habits, habit_histories)

    U->>FE: 로그 상세 화면 진입 (또는 주 이동)
    FE->>BE: GET /api/logs/{logId}/habit-records?week=YYYY-MM-DD
    BE->>DB: SELECT habits WHERE log_id=logId
    BE->>DB: SELECT habit_histories WHERE record_date BETWEEN weekStart~weekEnd
    DB-->>BE: 습관별 7일치 기록
    BE-->>FE: 200 OK {habits:[{records:[...]}]}
    FE-->>U: 요일별 체크 매트릭스 렌더링
```
