## 스터디 리스트 페이지

### 1. 최근 조회한 스터디

- LocalStorage를 활용하여 최근에 조회한 스터디를 표시

### 2. 스터디 목록 조회

- 페이지네이션
- 검색 기능
- 포인트 순 정렬 (오름차순/내림차순), 최신 순 정령, 오래된 순 정렬

## 스터디 만들기 페이지

### 1. 스터디 생성 폼

- 닉네임
- 스터디 이름
- 스터디에 대한 간단한 소개
- 배경 선택
- 비밀번호 및 비밀번호 확인

## 스터디 페이지

### 1. 스터디 상세 정보 조회

- 응원 이모지 (상위 3개 이모지 및 개수)
- 스터디 이름
- 생성자 닉네임
- 스터디 소개글
- 스터디 포인트
- 습관 기록표 (습관 기록표는 오늘의 습관에서 수정 가능)

### 2. 스터디 삭제

- 비밀번호 입력 -> 스터디 생성했을때 등록한 비밀번호와 일치하면 삭제 가능

### 3. 스터디 수정

- 비밀번호 입력 -> 스터디 생성했을때 등록한 비밀번호와 일치하면 수정 가능

### 4. 오늘의 습관 들어가기

- 비밀번호 입력 -> 일치하면 오늘의 습관 조회 가능

### 5. 오늘의 집중

- 비밀번호 입력 -> 일치하면 오늘의 집중 조회 가능

## 오늘의 습관 페이지

### 1. 오늘의 습관 조희

- 현재 시간 표시, 오늘의 습관 목록 조회

### 2. 오늘의 습관 생성

- 매일 반복될 습관 설정

### 3. 오늘의 습관 체크

- 지킨 습관 체크, 체크 해제
- 체크한 습관은 상세 페이지의 습관 기록표에 기록. 습관 기록표에서는 일주일 단위로 습관 기록 조회

### 4. 오늘의 습관 수정

- 습관 이름 수정 시, 해당 습관과 연관된 모든 습관의 이름 변경
- 습관 삭제 시, 습관이 오늘부터 종료되고 이전 기록에는 영향을 주지 않음
- 새로운 습관 추가할 경우, 오늘부터 새로운 습관 추가, 이전 날짜의 습관 기록표에서는 표시되지 않음

## 오늘의 집중 페이지

### 1. 오늘의 집중 조회

- 현재까지 획득한 포인트 조회
- 타이머 조작 가능

### 2. 오늘의 집중 시작

- 타이머(공부 시간) 설정 후 시작 버튼 클릭

### 3. 오늘의 집중 완료

- 설정한 시간이 끝나면 집중 완료
- 집중 성공 시 기본 3포인트 + 설정 시간 10분당 1포인트 추가 지금
