# 기능 개요

사용자가 닉네임, 로그 이름 , 소개, 배경, 비밀번호를 입력하여 새로운 로그를 생성하는 기능

# 사용자 시나리오

1. 사용자가 로그 만들기 화면에 진입
2. 닉네임, 이름, 소개 입력
3. 배경 선택
4. 비밀번호/확인 입력
5. 만들기 버튼 클릭
6. 스터디 생성 완료 후 상세 페이지로 이동

# 입력 항목

| 필드명            | 타입                     | 필수 | 설명                        | 제약조건                                                                                                     |
| ----------------- | ------------------------ | ---- | --------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `nickname`        | string                   | Y    | 생성자 닉네임               | trim 후 2~12자, 공백만 입력 불가                                                                             |
| `name`            | string                   | Y    | 스터디 이름                 | trim 후 2~20자, 공백만 입력 불가                                                                             |
| `description`     | string                   | Y    | 소개 멘트                   | trim 후 최대 140자                                                                                           |
| `background`      | string                   | Y    | 배경값                      | `BG_GREEN`, `BG_YELLOW`, `BG_BLUE`, `BG_PINK`, `BG_IMG_DESK`, `BG_IMG_WINDOW`, `BG_IMG_TILE`, `BG_IMG_PLANT` |
| `password`        | string                   | Y    | 스터디 수정/삭제용 비밀번호 | 4~15자,                                                                                                      |
| 영문 + 숫자 조합  |
| `passwordConfirm` | string                   | Y    | 비밀번호 확인용.            |
| 저장하지 않음     | `password`와 일치해야 함 |

# 제약 조건

- 비밀번호는 스터디 수정/삭제 시에만 사용된다.
- 닉네임은 스터디 간 중복을 허용한다.
  - 로그인 없음
  - 계정 개념 없음
  - 한글, 영어 가능
  - 특수문자 불가능
- 로그 이름은 중복 불가능하다
  - 같은 이름의 로그가 존재할 수 없다.
- 소개 멘트는 필수로 작성해야 한다.
  - 1글자도 가능하다.
- 배경은 8종 중 반드시 1개를 선택해야 한다.
  - 기본 선택값은 첫 번째 항목인 BG_GREEN.(추후 수정 가능성 존재)
- 비밀번호는 영문+숫자 조합만 가능하다
  - 특수문자는 허용되지 않는다.(필요하다면 추가)
- 스터디 생성 직후 초기값 설정
  - `point`: 0
  - `accumulateDay`: 0
  - `emoji_id`: 없음

# 예외/에러 시나리오

1. 필수값 누락(nickname, name, background,password/Confirm), 글자수 초과, 특수문자 사용
   1. `INVALID_INPUT`
   2. 입력값이 유효하지 않습니다.
2. 로그 이름 중복
   1. `DUPLICATE_NAME`
   2. 이미 존재하는 스터디 이름입니다.
3. 닉네임, 로그 이름 글자수 초과
   1. 입력 시점에 글자수 제한으로 더 이상 입력되지 않게 한다.
4. 배경값 잘못 전달
   1. `INVALID_BACKGROUND`
   2. 존재하지 않는 배경 값입니다.
5. 비밀번호/비밀번호 확인 불일치
   1. `PASSWORD_MISMATCH`
   2. 비밀번호가 일치하지 않습니다.

# 화면 상태

- 기본 상태
  - 닉네임: `placeholder = “닉네임을 입력해주세요”`
  - 로그 이름: `placeholder = “로그 이름을 입력해주세요”`
  - 소개: `placeholder = “소개 멘트를 작성해 주세요”`
  - 비밀번호: `placeholder = “로그 이름을 입력해주세요”`
  - 비밀번호 확인: `placeholder = “비밀번호를 다시 한 번 입력해 주세요”`
  - 배경: 기본값: `BG_GREEN`
- 입력 중 상태
  - 해당 항목 색상 테두리(굵게)
  - 배경: 선택 표시
  - 소개: 내용이 늘어날 경우 내부 스크롤이 생기고 넘치는 내용은 잘린다.
- 유효성 에러 상태
  - 해당 항목 빨간 테두리
  - 하단 에러 메시지
    - 닉네임 누락: `“닉네임을 입력해주세요”`
    - 로그 이름 누락: `“로그이름을 입력해주세요”`
    - 로그 이름 중복: `“이미 존재하는 로그 이름입니다.“`
    - 소개 누락: `“소개 멘트를 작성해주세요”`
    - 비밀번호 확인 불일치:`“비밀번호가 일치하지 않습니다”`
- 비밀번호 표시/숨김
  - 눈 아이콘 클릭 시 마스킹 토글

# 완료 조건

- 모든 필수 값이 없으면 만들기 버튼이 비활성화 상태이다.
- 모든 필수값을 입력해야 하단 만들기 버튼이 활성화된다.
- 생성 성공 시 스터디 상세 화면으로 이동한다.
- 비밀번호는 화면에 마스킹 처리 되며, 보기 버튼을 누르면 원본이 보인다.
- 비밀번호와 비밀번호 확인이 일치하지 않으면 제출되지 않고 명확한 에러 메시지가 노출된다.
- 배경 8종 중 1개만 선택 가능하다(중복 선택 불가)
- 생성 실패(검증 실패/서버 오류) 시 입력했던 값은 유지된 채 에러만 노출되어 재입력 없이 재시도할 수 있다.
- 닉네임은 다른 스터디와 중복되어도 생성이 차단되지 않는다.

# 추가 논의 사항

- 만들기 버튼이 헤더, 하단 총 2개가 있는데 로그 만들기 화면에서는 헤더에 만들기 버튼이 없는게 낫지 않을까? 헤더 만들기 버튼은 만득기 폼으로 들어가는 역할만 하는 것 같다.
- 기본 단색 배경이 가을에 맞게 변경된다면 기본 배경색을 다른 것으로 지정해야 할 것 같다.
- 닉네임과 스터이 이름에 특수 문자를 허용할 것인가?
- 소개 멘트는 필수가 아니어도 되는가?
