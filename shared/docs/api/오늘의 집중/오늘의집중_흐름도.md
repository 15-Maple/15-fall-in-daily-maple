# 오늘의 집중 API 요청 흐름도 (3개)

API 1개당 요청/응답 시퀀스를 1개 다이어그램으로 정리했습니다.

---

## 1. 오늘의 집중 조회

`GET /api/logs/{logId}/focus`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(오늘의 집중)
    participant BE as 백엔드
    participant DB as DB(logs, focus_records)

    U->>FE: 오늘의 집중 화면 진입
    FE->>BE: GET /api/logs/{logId}/focus
    BE->>DB: SELECT points FROM logs WHERE id=logId
    BE->>DB: SELECT focus_records WHERE log_id=logId AND status=진행중
    DB-->>BE: 현재 포인트 + 진행 중 세션(있으면)
    BE-->>FE: 200 OK {points, activeSession}
    alt activeSession = null
        FE-->>U: "25:00 Start" 초기 화면
    else activeSession 존재
        FE-->>U: 진행 중인 타이머 화면 복원
    end
```

---

## 2. 오늘의 집중 시작

`POST /api/logs/{logId}/focus`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(오늘의 집중)
    participant BE as 백엔드
    participant DB as DB(focus_records)

    U->>FE: 목표 시간 설정 후 Start!
    FE->>BE: POST /api/logs/{logId}/focus {targetSeconds}
    alt 이미 진행 중인 세션 존재
        BE-->>FE: 409 Conflict
    else 정상
        BE->>DB: INSERT INTO focus_records (status=진행중, created_at=now)
        DB-->>BE: focusId 반환
        BE-->>FE: 201 Created {focusId, status:"진행중", ...}
        FE-->>U: 타이머 카운트다운 시작
    end
```

---

## 3. 오늘의 집중 완료

`PATCH /api/focus-records/{focusId}/complete`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(오늘의 집중)
    participant BE as 백엔드
    participant DB as DB(focus_records, logs, point_histories)

    Note over FE: 타이머가 targetSeconds 만큼 진행
    FE->>BE: PATCH /api/focus-records/{focusId}/complete
    BE->>BE: now - created_at >= targetSeconds 검증
    alt 아직 목표 시간 전
        BE-->>FE: 400 Bad Request
    else 목표 시간 도달
        BE->>DB: UPDATE focus_records SET status=완료, ended_at=now
        BE->>BE: pointsEarned = 3 + floor(targetSeconds / 600)
        BE->>DB: UPDATE logs SET points += pointsEarned
        BE->>DB: INSERT INTO point_histories (사유: "오늘의 집중 완료")
        DB-->>BE: 갱신 완료
        BE-->>FE: 200 OK {pointsEarned, totalPoints, ...}
        FE-->>U: 포인트 획득 표시
    end
```
