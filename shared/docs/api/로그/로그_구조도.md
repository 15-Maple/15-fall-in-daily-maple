# 로그 API 구조도 (8개)

프론트 → 백엔드 → DB 관계를 API 1개당 다이어그램 1개로 정리했습니다.

---

## 1. 로그 목록 조회

`GET /api/logs`

```mermaid
flowchart LR
  FE["프론트\n메인화면(로그 목록)"] -->|"GET /api/logs\n?keyword&sort&cursor&size"| BE["백엔드\n로그 목록 조회"]
  BE -->|"SELECT ... ORDER BY sort\nLIMIT size"| DB1[("logs")]
  BE -->|"SELECT reactionType, COUNT(*)\nGROUP BY reactionType\nLIMIT 3"| DB2[("reactions")]
```

---

## 2. 로그 생성

`POST /api/logs`

```mermaid
flowchart LR
  FE["프론트\n로그 생성 화면"] -->|"POST /api/logs\n{nickname,name,description,\nbackground,password,passwordConfirm}"| BE["백엔드\n로그 생성"]
  BE -->|"INSERT"| DB1[("logs")]
```

## 4. 로그 수정

`PATCH /api/logs/{logId}`

```mermaid
flowchart LR
  FE["프론트\n로그 상세 화면\n(수정하기)"] -->|"PATCH /api/logs/{logId}\n{password,name,description,background}"| BE["백엔드\n로그 수정"]
  BE -->|"① SELECT password 대조"| DB1[("logs")]
  BE -->|"② UPDATE name/description/background"| DB1
```

---

## 5. 로그 삭제

`DELETE /api/logs/{logId}`

```mermaid
flowchart LR
  FE["프론트\n로그 상세 화면\n(삭제하기)"] -->|"DELETE /api/logs/{logId}\n{password}"| BE["백엔드\n로그 삭제"]
  BE -->|"① SELECT password 대조"| DB1[("logs")]
  BE -->|"② DELETE (CASCADE)"| DB1
  DB1 -.CASCADE.-> DB2[("habits")]
  DB1 -.CASCADE.-> DB3[("focus_records")]
  DB1 -.CASCADE.-> DB4[("point_histories")]
  DB1 -.CASCADE.-> DB5[("reactions")]
```

## 6. 응원 이모지 조회

flowchart LR

## 8. 습관 기록표(주간뷰) 조회

`GET /api/logs/{logId}/habit-records`

```mermaid
flowchart LR
  FE["프론트\n로그 상세 화면\n(습관 기록표 영역)"] -->|"GET /api/logs/{logId}/habit-records\n?week=YYYY-MM-DD"| BE["백엔드\n습관 기록표 조회"]
  BE -->|"SELECT habits\nWHERE log_id=logId"| DB1[("habits")]
  BE -->|"SELECT habit_histories\nWHERE record_date BETWEEN weekStart~weekEnd"| DB2[("habit_histories")]
```
