# 오늘의 습관 API 요청 흐름도 (5개)

API 1개당 요청/응답 시퀀스를 1개 다이어그램으로 정리했습니다.

---

## 1. 오늘의 습관 목록 조회

`GET /api/logs/{logId}/habits`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(오늘의 습관)
    participant BE as 백엔드
    participant DB as DB(habits, habit_histories)

    U->>FE: 오늘의 습관 화면 진입
    FE->>BE: GET /api/logs/{logId}/habits?cursor&size
    BE->>DB: SELECT habits WHERE log_id=logId ORDER BY deleted_at, created_at
    BE->>DB: SELECT habit_histories WHERE record_date=오늘
    DB-->>BE: 습관 목록 + 오늘 체크 여부
    BE-->>FE: 200 OK {currentTime, date, habits:[...]}
    FE-->>U: 현재 시각 + 습관 목록 렌더링
```

---

## 2. 습관 생성

`POST /api/logs/{logId}/habits`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(습관 목록수정 모달)
    participant BE as 백엔드
    participant DB as DB(habits)

    U->>FE: '+' 클릭 후 습관 이름 입력
    FE->>BE: POST /api/logs/{logId}/habits {name}
    alt name 누락
        BE-->>FE: 400 Bad Request
    else 정상
        BE->>DB: INSERT INTO habits (deleted_at=NULL)
        DB-->>BE: habitId 반환
        BE-->>FE: 201 Created {habitId, name, ...}
        FE-->>U: 습관 목록에 즉시 추가
    end
```

---

## 3. 습관 이름 수정

`PATCH /api/habits/{habitId}`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(습관 목록수정 모달)
    participant BE as 백엔드
    participant DB as DB(habits)

    U->>FE: 습관 이름 수정
    FE->>BE: PATCH /api/habits/{habitId} {name}
    BE->>BE: habitId가 현재 로그 세션 소속인지 검증
    alt 다른 로그 소속(IDOR)
        BE-->>FE: 403 Forbidden
    else 정상
        BE->>DB: UPDATE habits SET name
        DB-->>BE: 갱신 완료
        BE-->>FE: 200 OK {name, updatedAt}
        FE-->>U: 이름 변경 (과거 습관 기록표에도 소급 반영)
    end
```

## 4. 습관 삭제(비활성화)

`PATCH /api/habits/{habitId}/deactivate`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(습관 목록수정 모달)
    participant BE as 백엔드
    participant DB as DB(habits)

    U->>FE: 휴지통 아이콘 클릭
    FE->>BE: PATCH /api/habits/{habitId}/deactivate
    BE->>BE: habitId가 현재 로그 세션 소속인지 검증
    alt 이미 비활성화됨
        BE-->>FE: 409 Conflict
    else 정상
        BE->>DB: UPDATE habits SET deleted_at=now
        DB-->>BE: 갱신 완료
        BE-->>FE: 200 OK {isActive:false, deletedAt}
        FE-->>U: 오늘 이후 "오늘의 습관" 목록에서 제외\n(과거 습관 기록표는 유지)
    end
```

## 5. 습관 체크/체크 해제

`PUT /api/habits/{habitId}/check`

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as 프론트(오늘의 습관 화면)
    participant BE as 백엔드
    participant DB as DB(habit_histories)

    U->>FE: 습관 항목 클릭
    FE->>BE: PUT /api/habits/{habitId}/check {isChecked}
    BE->>BE: habitId가 현재 로그 세션 소속인지 검증
    BE->>BE: record_date = 서버 기준 오늘(Asia/Seoul)로 고정
    BE->>DB: (habit_id, record_date) row 있으면 UPDATE, 없으면 INSERT
    DB-->>BE: 반영 완료
    BE-->>FE: 200 OK {habitId, date, isChecked}
    FE-->>U: 체크 상태 즉시 반영 (습관 기록표에도 기록)
```
